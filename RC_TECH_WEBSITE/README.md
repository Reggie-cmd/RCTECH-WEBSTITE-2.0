# RC TECH — Web Development POE

## 1. Project Overview

**Project Name:** RC TECH  
**Project Type:** Electronics and Technology Accessories Website  
**POE Stage:** Part 1 — Initial Website Development

RC TECH is a proposed electronics accessories business website designed to help visitors explore products, learn about the business, and make product or general enquiries. The website uses a technology-inspired visual identity with blue, navy, white and light-blue colours.

## 2. Project Objectives

The objectives of the website are to:

- Introduce the RC TECH business concept.
- Display electronics accessories in an organised product catalogue.
- Provide an enquiry form for product-related questions.
- Provide a contact form for general questions and feedback.
- Create a consistent and easy-to-navigate website.
- Establish a foundation for future improvements in Parts 2 and 3.

## 3. Target Audience

The target audience includes people looking for everyday electronics accessories, such as charging cables, chargers, phone covers, adapters and audio accessories.

## 4. Website Pages

| Page | Description |
|---|---|
| `index.html` | Introduces RC TECH and provides links to the main website sections. |
| `about.html` | Explains the business concept, mission, vision and target audience. |
| `products.html` | Displays example electronics accessories. |
| `enquiry.html` | Allows visitors to enquire about products. |
| `contact.html` | Provides a form for general enquiries and feedback. |

## 5. Technologies Used

- HTML5 — website structure and content.
- CSS3 — styling and page presentation.
- JavaScript — basic website interactions.
- SVG — scalable illustrations.
- GitHub — source-code repository and version control.
- Chrome Developer Tools — website inspection and testing.

## 6. Part 1 Details

Part 1 established the RC TECH concept and initial website structure. The website contains five HTML pages, navigation links, example product listings, enquiry and contact forms, and initial visual styling.

The website is an academic prototype. Any forms or business features must be tested before being described as fully operational services.
