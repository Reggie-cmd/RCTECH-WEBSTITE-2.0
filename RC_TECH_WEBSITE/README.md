# RC TECH — Web Development POE 2026 Part 1
Student: Ratang Ramoroka
Project: RC TECH Electronics Website

## Overview
RC TECH is a small electronics retail website concept focused on practical technology accessories.

## Goals
- Present products clearly.
- Provide simple navigation.
- Allow product enquiries.
- Provide a general contact route.
- Create a foundation for Parts 2 and 3.
